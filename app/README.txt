================================================================================
ITALIANO
================================================================================
Zapp2md trasforma l'esportazione di una chat WhatsApp (con vocali, foto, video e
documenti) in un unico documento Markdown (.md) in ordine cronologico, pronto da
analizzare con un LLM come Claude, ChatGPT o Gemini, o con altri strumenti di AI.
Tutto viene elaborato sul tuo computer: nessun dato viene inviato a servizi esterni.

COSA ESTRAE
- Messaggi vocali e audio: trascrizione completa (Whisper), lingua riconosciuta.
- Video: trascrizione della traccia audio (facoltativa).
- Immagini: testo visibile (OCR di Windows), dimensioni, dati EXIF se presenti.
- Documenti: PDF (anche scansionati), Word, Excel, PowerPoint, TXT/CSV, contatti.

USO
1. Sul telefono: chat > nome del contatto (o menu) > Esporta chat > Allega media.
   Porta il file .zip sul PC. (Con "Senza media" i vocali non sono nel file:
   il programma lo segnala.)
2. Apri Zapp2md, scegli il file .zip e premi Avvia. Puoi anche trascinare il .zip
   sull'icona di Zapp2md.
3. La finestra mostra avanzamento, tempo rimanente, file elaborati per tipo ed
   eventuali errori. "Interrompi" non fa perdere il lavoro: con "Avvia" riprende.
4. Al termine: "Apri il risultato" apre il file .md da caricare nel tuo LLM.

Tempi indicativi (PC senza scheda video dedicata): un vocale breve circa 6-8 secondi,
un'ora di audio circa 30-40 minuti.

MENU START
- Zapp2md: il programma.
- Ripara Zapp2md: verifica i componenti e scarica solo quelli mancanti o danneggiati.
- Ripara Zapp2md (reinstallazione completa): riscarica tutto da zero.

DISINSTALLAZIONE: Impostazioni > App > Zapp2md > Disinstalla.

================================================================================
PORTUGUÊS
================================================================================
O Zapp2md transforma a exportação de uma conversa do WhatsApp (com mensagens de voz,
fotos, vídeos e documentos) num único documento Markdown (.md) em ordem cronológica,
pronto para analisar com um LLM como o Claude, o ChatGPT ou o Gemini, ou com outras
ferramentas de IA. Tudo é processado no seu computador.

UTILIZAÇÃO
1. No telemóvel: conversa > nome do contacto (ou menu) > Exportar conversa >
   Anexar multimédia. Copie o ficheiro .zip para o PC.
2. Abra o Zapp2md, escolha o .zip e prima Iniciar (ou arraste o .zip para o ícone).
3. A janela mostra o progresso, o tempo restante, os ficheiros por tipo e os erros.
4. No fim: "Abrir o resultado" abre o ficheiro .md para carregar no seu LLM.

MENU INICIAR: "Reparar Zapp2md" descarrega só o que falta; "Reparar Zapp2md
(reinstalação completa)" descarrega tudo de novo.

================================================================================
ENGLISH
================================================================================
Zapp2md turns a WhatsApp chat export (with voice messages, photos, videos and
documents) into a single chronological Markdown (.md) document, ready to analyse
with an LLM such as Claude, ChatGPT or Gemini, or other AI tools.
Everything is processed on your computer.

USE
1. On the phone: chat > contact name (or menu) > Export chat > Attach media.
   Copy the .zip file to the PC.
2. Open Zapp2md, choose the .zip and press Start (or drag the .zip onto the icon).
3. The window shows progress, time remaining, files per type and any errors.
4. When finished: "Open result" opens the .md file to upload to your LLM.

START MENU: "Repair Zapp2md" downloads only what is missing; "Repair Zapp2md
(full reinstall)" downloads everything again.
